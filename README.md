# Rahul Sehrawat — Engineering & Cybersecurity Portfolio

> **"Building intelligent systems and exploring cybersecurity through practical engineering."**

A modern, high-performance developer portfolio engineered with **Next.js 16**, **TypeScript**, **Tailwind CSS**, and interactive **3D micro-interactions**. Built to showcase practical implementations in systems programming, web application security testing, networking, and applied AI/ML.

---

## ⚡ Tech Stack

* **Framework:** [Next.js 16](https://nextjs.org) (App Router, Server & Client Components)
* **Language:** TypeScript
* **Styling:** [Tailwind CSS](https://tailwindcss.com) with custom dark cyber theme & glassmorphism
* **3D & Canvas:** Three.js / Canvas interactive cyber shield background
* **Icons:** [Lucide React](https://lucide.dev)
* **ORM & Database:** Prisma with SQLite persistence
* **SEO & Metadata:** Automated Sitemap, Robots.txt, Open Graph, and Twitter Card schemas

---

## 🚀 Key Sections & Architecture

1. **Cyber Hero Terminal:** Real portrait with 3D cyber frame, verified badge, and live interactive terminal command typewriter.
2. **Academic & Professional Journey:** Interactive timeline detailing B.Tech Computer Science & Engineering (AI & ML) at SGT University.
3. **Categorized Skills Matrix:** Interactive category filter (`Programming`, `Cybersecurity`, `AI / ML`, `Development Tools`) with realistic competency tags (`Proficient`, `Project Exp`, `Practicing`, `Learning`).
4. **Featured Deep-Dive Projects:**
   * **NEXCLASS:** Smart Classroom Management System (Next.js, Python, Prisma, SQLite, AI Analytics).
   * **Tic Tac Toe LAN:** Real-time multi-threaded TCP socket multiplayer game built from scratch in Python with Tkinter GUI.
   * **Security Management System:** Premise security checkpoint application applying singly linked lists, LIFO action stacks, circular queues, and SQLite.
   * **Contact Management System:** Custom dynamic linked list implementation with alphabetized insertion, search algorithms, and persistent file serialization.
5. **Verified Credentials & Achievements Gallery:**
   * Interactive modal lightbox for inspecting high-resolution certificates.
   * Direct verification links and signed original PDF documents (Microsoft Azure AZ-900, Azure AI-900, ASD Academy Linux, Networking, WiFi Pentesting, Ethical Hacking, IDEATHON 8.0 2nd Position Winner, SYNERGY 2025 Project Showcase).
6. **Cybersecurity Practice Lab:** Dedicated educational lab environments covering OWASP Top 10, HTTP traffic analysis, Wireshark packet inspection, and web application vulnerability assessment.
7. **Contact Hub:** Direct 1-click email copy, social links, and authenticated API submission route with bot honeypot protection.

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rsherawat2007-create/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment configuration
Copy the example environment configuration:
```bash
cp .env.example .env.local
```

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production Build
```bash
npm run build
npm run start
```
